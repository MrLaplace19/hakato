# Конструктор уроков английского для детей

Инструмент для создания увлекательных уроков английского языка для детей разных возрастов.

## Возможности

- 📚 Создание уроков для детей от 1 до 15 лет
- supr. поддержка разных уровней владения языком
- 🎮 Интерактивные игры и активности
- 💾 Сохранение уроков в формате JSON
- 🎨 Простой консольный интерфейс

## Установка

### Базовые требования

```bash
# Установка зависимостей через uv
uv sync

# Или установка вручную
pip install -r requirements.txt
```

### GUI версия (опционально)

Для использования GUI меню требуется установить tkinter:

```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# Arch Linux
sudo pacman -S tk
```

## Использование

### Консольная версия (по умолчанию)

```bash
python main.py
```

Приложение запустится в интерактивном режиме, где вы сможете:
1. Выбрать тему урока (животные, цвета, еда и т.д.)
2. Указать возрастную группу
3. Выбрать уровень английского
4. Установить длительность урока
5. Получить готовый план урока
6. Сохранить урок в файл

### GUI версия

```bash
python main.py --gui
```

Откроется простое графическое окно для создания уроков с выпадающими списками для выбора параметров:
- Тема урока
- Возрастная группа
- Уровень английского
- Длительность урока

После нажатия кнопки "Создать урок" вы увидите готовый план урока в текстовом поле ниже.

## Тестирование

Для проверки работы без интерактивного ввода:

```bash
python test_builder.py
```

Это создаст тестовый урок и сохранит его в файл.

## Структура проекта

- `main.py` - точка входа приложения
- `base_c.py` - основная логика конструктора уроков
- `menu.py` - GUI меню (опционально)
- `test_builder.py` - тестовый скрипт

## Примеры использования

### Программное создание урока

```python
from base_c import ConsoleLessonBuilder, AgeGroup, EnglishLevel

builder = ConsoleLessonBuilder()
lesson = builder._generate_lesson(
    theme="животные",
    age_group=AgeGroup.PRESCHOOL,
    en_level=EnglishLevel.BEGINNER,
    duration=45
)

print(lesson.get_lesson_plan())
```

## Формат сохранения

Уроки сохраняются в JSON файлы с следующей структурой:

```json
{
  "title": "Название урока",
  "theme": "тема",
  "age_group": "возрастная группа",
  "en_level": "уровень английского",
  "duration": 45,
  "objectives": ["цель 1", "цель 2"],
  "vocabulary": ["слово1", "слово2"],
  "activities": [...]
}
```
